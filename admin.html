Variables Railway

Variables d'environnement requises

Ces variables doivent être définies dans Railway → ton projet → Variables :

GROQ_API_KEY = gsk_… (génération d'articles)
ADMIN_PASSWORD = ton_mot_de_passe (par défaut: onemedia2026!)
RESEND_API_KEY = re_… (newsletter)
DATA_DIR = /data (Volume Railway → persistance données)
📡 Flux RSS & SEO

Flux RSS & Sitemap générés automatiquement

RSS Feed https://one-media-production.up.railway.app/rss.xml ↗ Tester

💡 Google Search Console : Sitemaps → colle l'URL du sitemap → Soumettre.

💾 Persistance données (Railway Volume)

Rendre les données permanentes

Sans volume, articles et médias sont effacés à chaque redéploiement.

  1. Railway Dashboard → ton service → Volumes → New Volume
  2. Mount Path : /data
  3. Variables → Ajouter : DATA_DIR=/data
  4. Redéployer → tout est maintenant permanent ✅
